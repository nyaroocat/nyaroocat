WebMCP를 지원하지 않는 일반 브라우저에서는 아래 시뮬레이션 버튼으로 도구 로직을 직접 검증할 수 있습니다.

③ 도구 호출 기록 (실시간)

아직 호출이 없습니다. ChatGPT가 도구를 호출하면 여기에 표시됩니다.

④ ChatGPT 데스크톱 앱에서 확인하는 방법

  1. ChatGPT 데스크톱 앱을 최신 버전으로 업데이트 (Site tools는 구버전에 없음)
  2. 모델을 GPT-5.6 Sol 또는 GPT-6 Sol로 선택 (Luna는 WebMCP 비활성)
  3. 앱의 내장 브라우저에서 이 페이지 열기 — 주소창에
  4. 주소창의 「Site tools」 클릭 → Available site tools에 3개 도구가 보이는지 확인
  5. 채팅에 입력: "사이트 도구 webmcp_ping 호출해 줘" → ③ 기록에 호출이 찍히면 성공!
  6. 이어서: "get_workflow_summary로 워크플로 보여줘", "build_test_prompt로 주제 '고양이 기사', 스타일 '수채화' 프롬프트 만들어줘"

⑤ 참고

· ChatGPT 내장 브라우저는 WebMCP 명령형(Imperative) API만 지원 (HTML 폼 선언형 API·iframe 미지원)
· 도구는 HTTPS(보안 컨텍스트) 최상위 페이지에서 등록해야 함 → GitHub Pages 배포 사용
· 각 도구 호출 전 ChatGPT 브라우저의 안전 검토가 있으며 승인 절차가 표시될 수 있음
· 이 페이지는 v2.0 통합 전 검증 전용 — 기존 gpt-image-node-studio.html은 그대로 동작함
