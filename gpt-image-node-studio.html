🤖 ChatGPT 앱 연동

⏳ Site tools 연결 상태 확인 중…
API 키 없이, 지금 노드 구성을 ChatGPT 앱이 읽을 수 있는 명령으로 만들어 줘요. 버튼을 누르면 명령이 자동 복사돼.
ChatGPT 데스크톱 내장 브라우저에서는 Site tools의 build_image_prompt 도구도 같은 데이터를 반환해요.

🧠 기본 노드 구성

① 🧑 캐릭터 — 인물·대상 외형
② 🎨 스타일 — 화풍·질감
③ 🎬 연출 — 구도·조명·배경
④ 📐 출력 — 이미지 크기·품질
⑤ ➕ 추가 내용 / 🖼 이미지 / ✨ 보정으로 계속 확장

✅ 빈칸 처리 규칙

빈 캐릭터·스타일·연출 노드가 있어도 명령이 막히지 않아요. ChatGPT가 참조 이미지와 추가 내용을 기준으로 빈 항목을 자연스럽게 보완하도록 지시합니다.

🧭 사용 흐름

① 기본 노드의 내용을 입력하거나, 비워 둬도 돼요
② ➕ 추가 내용 / 🖼 이미지 / ✨ 보정 노드로 확장
③ 각 노드를 조합 노드에 연결하고, 조합을 GPT 명령 노드에 연결
④ GPT앱으로 명령하기 버튼 클릭!
